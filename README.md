# Event-Driven Host Activity Monitor (Mini-EDR Agent)

Кроссплатформенный (Windows / Linux) асинхронный монитор активности хоста на C++17, использующий нативные событийные API операционных систем для мгновенного отслеживания изменений файловой системы и мониторинга процессов.

Проект разработан в учебных целях для демонстрации принципов работы систем обнаружения угроз на конечных точках (EDR - Endpoint Detection and Response).

---

## 🚀 Ключевые возможности

*   **Событийный мониторинг файлов (0% CPU в режиме ожидания):**
    *   **Windows:** Использование системного вызова `ReadDirectoryChangesW` для асинхронного перехвата событий файловой системы.
    *   **Linux:** Использование подсистемы ядра `inotify` для подписки на события каталогов.
*   **Мониторинг процессов в реальном времени:**
    *   Определение имени процесса, его идентификатора (**PID**) и идентификатора родительского процесса (**PPID**).
    *   Контроль запусков новых процессов и завершения работы существующих.
*   **Криптографическая верификация:**
    *   Генерация контрольных сумм для измененных файлов для обнаружения скрытых модификаций (например, атак типа *Timestomping*).
*   **Высокая производительность:**
    *   Архитектура на основе потоков (`std::thread`): мониторинг файловой системы вынесен в асинхронный фоновый поток, что предотвращает блокировку основного потока выполнения.

## 🛠️ Архитектура

Проект состоит из двух независимых модулей, управляемых общим контроллером:

```
                          ┌──────────────────────────┐
                          │    Host Monitor Core     │
                          └────────────┬─────────────┘
                                       │
                ┌──────────────────────┴──────────────────────┐
                ▼                                             ▼
  ┌───────────────────────────┐                 ┌───────────────────────────┐
  │   Process Watcher         │                 │   Event File Watcher      │
  │   (Polling/Snapshot)      │                 │   (ReadDirectory/inotify) │
  └─────────────┬─────────────┘                 └─────────────┬─────────────┘
                │                                             │
                └──────────────────────┬──────────────────────┘
                                       ▼
                        ┌────────────────────────────┐
                        │      Console Logging       │
                        │   [PROC CREATE] / [FILE]   │
                        └────────────────────────────┘
```

## 💻 Требования к среде

*   Компилятор с поддержкой стандарта **C++17** (`GCC 8+`, `Clang 7+` или `MSVC 2019+`).
*   Права администратора / суперпользователя (`root`/`Administrator`) для корректного доступа к системным API процессов.

## 📦 Сборка проекта

### Linux (GCC / Clang)
Для сборки не требуются внешние зависимости, кроме стандартной библиотеки и системных заголовков.

```bash
# Компиляция с использованием стандарта C++17
g++ -std=c++17 main.cpp -o host_monitor

# Запуск с правами суперпользователя для чтения структуры процессов
sudo ./host_monitor
```

### Windows (MinGW)
```cmd
# Компиляция с линковкой системных библиотек
g++ -std=c++17 main.cpp -o host_monitor.exe -lpsapi

# Запустите командную строку от имени Администратора и выполните:
host_monitor.exe
```

### Windows (Microsoft Visual Studio)
1. Создайте пустой проект **C++ Console Application**.
2. Добавьте файл `main.cpp` в исходные файлы.
3. В свойствах проекта перейдите в **Configuration Properties -> C/C++ -> Language** и установите **C++ Language Standard** на `ISO C++17 Standard`.
4. Соберите проект в конфигурации `Release` (x64).

## ⚙️ Настройка под себя

Вы можете легко изменить область мониторинга. Откройте `main.cpp` и найдите функцию `main()`:

*   **Изменение отслеживаемой папки:**
    Замените `fs::current_path().string()` на любой интересующий вас путь:
    ```cpp
    // Пример для Windows
    EventFileSystemWatcher fileWatcher("C:\\Windows\\System32");
    
    // Пример для Linux
    EventFileSystemWatcher fileWatcher("/etc");
    ```
*   **Изменение частоты сканирования процессов:**
    В бесконечном цикле `while` измените время ожидания:
    ```cpp
    std::this_thread::sleep_for(std::chrono::milliseconds(500)); // Опрос каждые 0.5 сек
    ```
